# Приложение - Список покупок

##  Стек технологий
- **Архитектура:** MVI 
- **Тип проекта:** Многомодульный
- **UI:** Jetpack Compose
- **DI:** Hilt
- **База данных:** SQLite



## Архитектура проекта

Проект реализован с использованием Clean Architecture и MVI.

Слои:
- presentation — Compose UI + ViewModel
- domain — UseCase и модели
- data — Repository, Firebase, SQLite
